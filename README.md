# myjournal

A personal journaling web app with a **gratitude journal** and a daily **life check-in** (me, relationships, work), plus weekly and monthly reviews. Every entry is saved as Markdown to a private GitHub repo.

- **Plan:** [PLAN.md](PLAN.md) covers architecture, the data repo's folder structure, entry formats, roadmap and decisions.
- **UI prototypes:** open [`prototypes/index.html`](prototypes/index.html) in a browser for three clickable wireframe directions:
  - A · Notebook (desktop-first)
  - B · Guided (mobile-first, one question at a time)
  - C · Dashboard (insight-first)
