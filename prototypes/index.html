myjournal: three UI directions

Each prototype is clickable and covers the same four screens: Connect (first run), Today (gratitude + life check-in), History and Check-in. Use the dark bar at the top of each one to switch screens. Yellow notes show which file in your private repo each action writes.

Direction A

Notebook

desktop-firsteasiest to build

One calm page per day with a sidebar calendar. Gratitude on top, the life check-in (me / relationships / work) underneath, one Save button.

  • Feels like a real journal
  • Everything visible at once
  • Less suited to a quick phone entry
Open prototype →
Direction B

Guided

mobile-firstbest for habit

One question per screen with a progress bar, like a short conversation. Choose a 4-minute full check-in or a 60-second "just gratitude".

  • Lowest friction, every day
  • Great as an installable phone app
  • Harder to see the whole day at a glance
Open prototype →
Direction C

Dashboard

insight-firstmost to build

Today's quick entry sits next to your streak, mood trend and life-balance bars, with a live preview of the Markdown file being written. Includes a year heatmap and a monthly review.

  • Shows patterns while you write
  • Live file preview makes the GitHub storage visible
  • Needs charts + index, so best added later (Phase 4)
